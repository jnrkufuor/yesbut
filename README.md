# YesBut — read the fine print without reading the fine print

YesBut reads contracts and terms & conditions, explains them in plain English, and points out the gotchas:
**red flags** (red), **heads-ups** (blue) and **good news** (green).

**Ways to check something:**
- **Scan it.** Snap paper pages with the camera. Text is read on the phone (Google ML Kit).
- **Upload.** PDF, TXT, HTML, Markdown or RTF.
- **Paste text.** Paste straight from the clipboard.
- **Drop a link.** YesBut fetches any terms page and cleans it up before checking it.
- **Library.** Popular terms (Netflix, Spotify, Uber, Adobe…) fetched live, so you always get the current version.

**Two engines:**
- **Offline (default).** Instant and private. 37 gotcha rules and a 38-term jargon decoder in `assets/rules.json`.
- **AI (Claude).** Optional. Gives breakdowns specific to the document. Add an Anthropic API key in Settings. If the AI call fails, YesBut switches to the offline engine automatically.

## Get the APK

### Option A: GitHub builds it for you (no setup)
1. Create a new GitHub repo and upload this folder. Any method works, including dragging the files into the GitHub web UI.
2. Open the **Actions** tab. **Build Android APK** runs on every push, and you can also start it by hand.
3. Wait about 8–12 minutes, open the finished run, and download **YesBut-apk**. Unzip it to get `app-release.apk`.
4. Send the APK to your Android phone and open it. You may need to allow "Install unknown apps".

### Option B: Build on your Mac
```bash
brew install --cask flutter        # once
flutter doctor                     # follow any Android SDK prompts (Android Studio works)
cd yesbut
./tool/build_apk.sh                # → YesBut.apk in this folder
```
To run it live on a plugged-in phone or emulator: `./tool/setup_platforms.sh && flutter run`.

> The `android/` and `ios/` folders are generated by `flutter create` so they always match your Flutter version.
> YesBut's own Android changes (app name, icon, internet permission, ProGuard rules) live in `platform_overlay/` and get copied on top.

## Project layout (built to scale)

```
lib/
  models/analysis.dart          Data model (JSON in/out). Shared by every engine.
  services/
    analysis/
      analyzer.dart             ContractAnalyzer interface. Add new engines here.
      rule_based_analyzer.dart  Offline engine (data-driven by assets/rules.json)
      claude_analyzer.dart      AI engine (Anthropic Messages API, configurable endpoint)
    ingestion/
      web_fetcher.dart          URL → clean text
      document_reader.dart      PDF/TXT/HTML/RTF → text
      scanner.dart              Camera/gallery → on-device OCR
    catalog_repository.dart     Library of known T&C pages (assets/catalog.json)
    storage.dart                Local persistence (swap for DB/cloud sync later)
  state/app_state.dart          Single ChangeNotifier: history, settings, engine choice + fallback
  theme/app_theme.dart          Colors, type, radii. One place to restyle the whole app.
  widgets/                      Reusable UI (tiles, score ring, loaders, buttons)
  screens/                      Home, Library, History, Paste, Link, Scan, Analyzing, Result, Settings
assets/
  rules.json                    YesBut rules + jargon. Edit to tune detection, no code changes.
  catalog.json                  Library entries. Can later be served from your backend.
  fonts/                        Google Sans Flex (OFL), the open successor to Product Sans
```

**Growing it:**
- **iOS.** The code is already cross-platform. Run `flutter build ipa` on a Mac with Xcode, and add the camera and photo usage strings to `ios/Runner/Info.plist`.
- **Web and desktop.** Paste, link and upload already work there. Scan uses ML Kit, which is mobile-only.
- **Backend.** Point Settings → Endpoint at your own server so no API key ships in the app. Serve `catalog.json` and `rules.json` remotely to update them without a new release.
- **Share sheet.** Add `receive_sharing_intent` so people can share a link or text into YesBut from any app.
- **Library cache.** Pre-analyze popular terms on a server so library results load instantly.
